RAG Pipeline
1

Document Input

Raw documents are added into the knowledge base.

2

Chunking

Documents are split into smaller semantic chunks.

3

Embeddings

Each chunk becomes a numerical vector representation.

4

Retrieval

The query embedding searches for semantically similar chunks.

5

Augmentation

Retrieved chunks are injected into the prompt as context for the LLM.

6

Generation

The LLM generates a grounded answer using the augmented prompt.
